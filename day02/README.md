# Day 02 — 바이브 코딩 툴 조사와 AI 서비스 모음 사이트

## 수업

오전에는 HTML이 브라우저 화면이 되는 원리를 배웠고, 오후에는 조별로 분야를 나눠 AI 서비스를 조사하고 한 사이트에 모았다.

## 만든 것

| 이름 | 내용 |
|---|---|
| [뽀모도로 (Claude)](pomodoro-claude/) | 같은 뽀모도로 앱을 Claude로 만든 버전. 시간 설정, 알림음 미리 듣기, 완료 기록 |
| [뽀모도로 (Codex)](pomodoro-codex/) | 같은 앱을 Codex로 만든 버전. 집중·짧은 휴식·긴 휴식 전환과 시간 설정 |
| [바이브 코딩 툴 조사](vibe-coding-research/) | 많이 쓰는 바이브 코딩 툴 7개의 기능, 요금, 사용률, 아쉬운 점 정리 |
| [AI 서비스 모음](ai-service-list/) | 조별로 조사한 AI 서비스를 분야별로 걸러 보고 검색하는 사이트 |

AI 서비스 모음은 조원들이 분야를 나눠 조사한 내용을 모은 사이트다. 이 레포에는 내가 맡은 바이브 코딩 분야 데이터만 남겼다.

## AI와 일한 방식

- **같은 요청을 두 도구에 맡겨 비교했다.** 동일한 프롬프트를 이용해서 뽀모도로 앱을 Claude와 Codex로 각각 만들었다. Claude 버전은 설정과 기록 기능까지 갖춘 1,300줄 정도의 앱이 됐고, Codex 버전은 핵심 기능만 담은 250줄 정도의 앱이 됐다.
- **조사를 세 AI에 따로 맡기고 서로 검증하게 했다.** Claude, Codex, Gemini에게 바이브 코딩 툴 조사를 각각 맡긴 뒤, Claude와 Codex에게 조사 결과를 공식 페이지와 대조하는 리뷰를 시켰다. 마지막에 세 조사와 두 리뷰를 [통합본](vibe-coding-research/vibe-coding-research.md)으로 합쳤다.
- **출처가 다른 수치는 섞지 않았다.** 설문마다 질문이 달라서 사용률을 합치거나 순위처럼 비교하지 않고, 수치마다 어느 설문인지 적었다.
