# Day 03 — 조별 사이트를 페이지별로 나눠 만들기

## 수업

조별로 취업 준비 사이트 "커리어 길잡이"를 만들었다. 메뉴마다 담당자를 정하고, 각자 Claude Code로 자기 페이지를 만든 뒤 한 폴더로 합쳤다.

## 만든 것

| 이름 | 내용 |
|---|---|
| [채용 공고 페이지](career-site-jobs/) | 조 사이트에서 내가 맡은 페이지. 가상 공고 20개를 직군·경력·AI 우대로 거르고, 검색하고, 마감일 순으로 정렬한다 |
| [코드 한 줄 타자 연습](typing-practice/) | VS Code 편집기를 흉내 낸 화면에서 코드 한 줄을 따라 치는 타자 연습. HTML, Python, CSS, JavaScript, Java 지원 |

채용 공고 페이지는 혼자 열리도록 공통 스타일(`style.css`)과 가상 공고 데이터(`jobs.js`)를 함께 두고, 다른 조원이 맡은 메뉴로 가는 링크는 지웠다. `style.css`는 디자인 담당 조원이 만들었고, `jobs.js`는 수업에서 받은 데이터다.

## AI와 일한 방식

- **규칙을 두 층으로 나눴다.** 조 전체가 지키는 공통 규칙은 맨 위 `CLAUDE.md`에, 내 페이지만의 규칙은 [`career-site-jobs/CLAUDE.md`](career-site-jobs/CLAUDE.md)에 적었다. 둘이 부딪히면 공통 규칙이 이긴다.
- **"다 됐다는 기준"을 확인할 수 있는 문장으로 썼다.** "개발을 고르면 5개가 보인다", "검색창에 React를 치면 J01만 보인다"처럼 써 두고, AI가 만든 결과를 이 기준으로 확인했다.
- **스펙에 결정 이유까지 남겼다.** 타자 연습 앱의 [`spec.md`](typing-practice/spec.md)에는 무엇을 만들지뿐 아니라 왜 그렇게 정했는지도 적었다. 한글 너비가 영문의 정확히 두 배라서 Jetendard 글꼴을 골랐고, CDN이 없어 글꼴 파일을 직접 넣으면서 라이선스 전문도 함께 두었다.
