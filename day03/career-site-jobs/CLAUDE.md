# 채용공고 페이지 — 담당: 개발

## 이 페이지를 보는 사람

- 채용 공고를 찾는 개발, 디자인, PO, 마케팅 직무 취업 준비생
- 신입 또는 경력 1~3년차 취업 준비생
- AI 활용을 우대하는 공고에 관심 있는 취업 준비생

## 이 페이지의 목적 (한 문장)

개발, 디자인, PO, 마케팅 직무 취업 준비생이 직군·경력·AI 우대 여부로 조건에 맞는 채용 공고를 쉽게 찾도록 돕는다.

## 꼭 들어갈 것 (3개 이하)

1. 직군별, 경력별, AI 우대 여부 필터링 기능
2. 공고 검색 기능 (회사 이름, 공고 제목, 태그에서 찾는다)
3. 마감일 순 정렬

## 다 됐다는 기준 (확인할 수 있는 문장으로)

- [x] 20개의 공고가 모두 화면에 보인다.
- [x] 개발을 고르면 5개가 보인다. 디자인·PO·마케팅도 각각 5개가 보인다.
- [x] AI 우대만 고르면 12개가 보인다.
- [x] 마감일 순으로 정렬하면 J08(10/28)이 맨 위, J20(12/10)이 맨 아래에 온다.
- [x] 검색창에 "React"를 치면 J01만 보인다.

## 이 페이지만의 규칙
- 필터를 여러 개 고르면 모두 만족하는 공고만 보여 준다.
- 맞는 공고가 없으면 "조건에 맞는 공고가 없어요. 필터를 줄여 보세요."라고 안내한다.
- 마감일 옆에 D-day를 표시한다.
