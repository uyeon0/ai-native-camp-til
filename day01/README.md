# Day 01 — 첫 웹 앱 두 개

## 수업

Claude 앱으로 업무를 자동화하는 방법을 다뤘다. 데이터 분석, 문서 생성, 대시보드, Cowork, 커넥터, 스킬까지 범위가 넓었다.

## 만든 것

자유롭게 이것저것 만들어 보는 시간에 내가 매일 쓸 만한 작은 웹 앱 두 개를 만들었다. AI로 개발하되, 앱 자체는 AI 없이 동작하게 했다.

| # | 이름 | 내용 |
|---|---|---|
| 001 | [오늘의 한 줄](001-daily-retro/) | 하루 한 줄 회고를 남기면 GitHub 잔디처럼 1년 격자에 쌓인다. localStorage 사용 |
| 002 | [커밋 메시지 빌더](002-commit-builder/) | type·scope·description을 칸별로 입력하면 Conventional Commits 메시지로 조합해 복사한다 |

둘 다 빌드 도구와 외부 라이브러리 없이 `index.html` 파일 하나로 만들었다.

## AI와 일한 방식

- 코드를 쓰기 전에 `docs/spec.md`에 스펙을 먼저 쓰고, 그 스펙을 기준으로 구현했다.
- 스펙에 **범위 밖** 항목(서버, 동기화, 모바일 사용성 등)을 명시해서 AI가 기능을 부풀리지 않게 했다.
- `CLAUDE.md`에 디렉토리 이름 규칙과 커밋 scope 규칙을 적어 두고, 프로젝트마다 같은 규칙을 따르게 했다.
