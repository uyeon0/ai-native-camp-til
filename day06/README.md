# Day 06 — 공공 API로 나만의 서비스 만들기

## 수업

API로 데이터를 받아 와서 나만의 서비스를 만들고 링크로 공개하는 날이었다. API는 주소로 주문하면 데이터가 배달되는 창구이고, API 키는 그 창구의 회원 카드라는 비유로 배웠다. 무료 API는 느리거나 멈출 수 있어서 로딩 중·불러오기 실패 화면이 꼭 필요하다는 점도 다뤘다.

## 만든 것

**[RANDOM SHELF](https://github.com/uyeon0/random-shelf)** · [배포 주소](https://random-shelf.netlify.app/)

국립세종도서관 사서들이 추천한 책 가운데 한 권을 무작위로 뽑아 주는 서비스다. 책 표지가 가로로 늘어선 룰렛을 돌리면 한 권에서 멈추고, 사서의 추천 글과 책 속 한 문장을 보여 준다.

- 수업은 키 없는 API를 쓰는 과제였지만, 쓰고 싶은 데이터가 키가 필요한 공공 API라서 Netlify Functions로 키를 숨기는 중계 함수를 만들었다.
- HTML, CSS, JavaScript만 쓰고 Netlify로 배포했다.

## AI와 일한 방식

- **문서를 먼저 세 개로 나눴다.** 기능과 데이터 규칙은 `기획서.md`, 화면은 `DESIGN.md`, API 조사와 표본 분석은 `자료조사.md`에 두고, `CLAUDE.md`에서 구현은 이 문서를 따르게 했다.
- **AI가 임의로 정하지 못하게 했다.** 두 문서가 어긋나거나 문서에 없는 값에 걸리면 한쪽을 골라 구현하지 말고 나에게 묻게 했다. 내가 정한 내용은 다시 문서에 반영했다.
- **API 키는 AI도 보지 못하게 했다.** `.env`는 내가 직접 만들고, Claude는 `.env`를 읽거나 키 값을 출력하지 않는다는 규칙을 `CLAUDE.md`에 적었다.
