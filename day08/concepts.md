# D8 개념 정리 — 카카오 지도 + 판다스

실습([`kakao-map`](kakao-map/))에서 직접 겪은 함정을 정리했다.

## 1. JavaScript 키는 숨길 수 없어서 도메인으로 제한한다

| | REST API 키 | JavaScript 키 |
| --- | --- | --- |
| 지키는 법 | `.env`에만 두고 HTML·화면에 넣지 않는다 | 카카오 콘솔에 등록한 도메인에서만 켜진다 |
| 남에게 보이면 | 사고. 바로 재발급 | 정상. 원래 브라우저로 가는 키 |

- JS 키는 브라우저가 지도를 그리려면 받아 가야 해서 숨길 방법이 없다. 대신 "`http://localhost:8501`에서만 켜진다"고 등록해 두면, 남이 베껴 가도 다른 사이트에서는 켜지지 않는다.
- REST 키에는 도메인 제한이 없어서 새면 누구나 내 쿼터로 검색할 수 있다.
- 확인: REST 키 앞글자로 `map.html`과 앱 화면을 검색해 0건인 것을 봤다. JS 키는 `map.html` 안에 있다(정상).

## 2. 좌표 순서가 API마다 뒤집힌다

- 카카오 로컬 API 응답은 `x` = 경도(124~132), `y` = 위도(33~39)이고, **문자열**로 온다. `float()`이 필요하다.
- 요청을 보낼 때도 `x=경도, y=위도`다.
- 지도 SDK는 `new kakao.maps.LatLng(위도, 경도)`로 **위도가 먼저**다. 응답 순서와 반대다.
- 뒤집으면 (127, 37) 같은 좌표가 되어 마커가 바다에 찍힌다. 그래서 한국 범위 밖 좌표는 버리게 했다.
- 확인: `geo.py 127.1085 37.3669`처럼 일부러 뒤집으니 "찾지 못했어요"가 나왔다.

## 3. `localhost`와 `127.0.0.1`은 카카오에게 다른 도메인이다

- 같은 컴퓨터를 가리켜도 카카오는 둘을 다른 주소로 본다. 등록한 쪽으로 열어야 지도가 뜬다. 포트까지 맞아야 한다.
- 로컬 서버는 `python -m http.server 8000 --bind 127.0.0.1`로 켠다. `--bind`를 빼면 같은 와이파이의 누구나 이 폴더에 들어와 `.env`까지 받아 갈 수 있다.
- 지도가 회색일 때 확인 순서: ① 카카오 콘솔에서 카카오맵 사용 설정이 켜져 있나 ② 지금 주소가 포트까지 등록됐나 ③ 등록한 주소로 열었나.
- 처음 `place.py`가 403을 받은 원인은 카카오맵 사용 설정이 꺼져 있던 것이었다.

## 4. 주소 검색과 키워드 검색은 좌표가 다르다

| | 주소 검색 (`geo.py`) | 키워드 검색 (`place.py`) |
| --- | --- | --- |
| API | `search/address.json` | `search/keyword.json` |
| 넣는 것 | 주소: "서울 종로구 세종대로 175" | 이름·검색어: "세종문화회관", "정자역 카페" |
| "세종문화회관" | 주소가 아니라 못 찾음 | 찾음 |
| 좌표 기준 | 주소(필지) 위치 | 장소(입구 등) 위치 |

- 같은 곳인데 두 좌표가 80m쯤 차이 났다.
- 주차장 CSV처럼 주소 칸이 있으면 주소 검색을, AI가 준 가게 이름을 확인할 때는 키워드 검색을 썼다.

## 5. 공공데이터 CSV 정리

전국주차장정보표준데이터(18,939줄 × 34칸)를 판다스로 정리했다.

| 원본 문제 | 처리 |
| --- | --- |
| 인코딩이 cp949라 그냥 열면 한글이 깨짐 | `utf-8-sig` → `cp949` 차례로 시도 |
| 필요 없는 칸이 많음 | 20칸만 남김 (전화번호·특기사항 제외) |
| 숫자가 문자열, 무료인 곳은 요금이 빈칸 | `pd.to_numeric`, 무료는 0 |
| 좌표 빈 줄 765개, 한국 밖 좌표 1개 | 걸러내고, 30줄만 카카오 주소 검색으로 채움 (27줄 성공) |

- 저장은 `utf-8-sig`로 해야 엑셀에서 한글이 깨지지 않는다.
- AI가 센 숫자는 검산했다: 강남역 1km 주차 구획 520면 = 247+45+50+118+9+51 ✅

## 덤: Folium을 쓰지 않은 이유

Folium은 파이썬만으로 지도(Leaflet·OpenStreetMap)를 그리는 라이브러리다. 키도 도메인 등록도 필요 없어서 카카오 지도가 안 뜰 때 대안이 된다. 하지만 이번에 익힐 것(JS 키, 도메인 제한, `LatLng` 순서)을 건너뛰게 되고 카카오 지도가 잘 떴으므로 쓰지 않았다.
