# Day 08 — 파이썬으로 카카오 지도와 공공데이터 다루기

## 수업

파이썬이 카카오 로컬 API로 장소와 좌표를 찾고, 그 결과를 브라우저가 카카오 지도에 그리는 흐름을 배웠다. 오후에는 판다스로 공공데이터 CSV를 정리해 지도에 올렸다.

실습하며 겪은 함정은 [개념 정리](concepts.md)에 따로 적었다.

- JavaScript 키는 숨길 수 없어서 도메인으로 제한한다
- 좌표 순서가 API마다 뒤집힌다
- `localhost`와 `127.0.0.1`은 카카오에게 다른 도메인이다
- 주소 검색과 키워드 검색은 좌표가 다르다
- 공공데이터 CSV 정리

## 만든 것

[kakao-map](kakao-map/): 미션마다 파이썬 파일 하나씩 만들었다.

| 파일 | 내용 |
|---|---|
| `place.py` | 키워드로 장소 검색 |
| `geo.py` | 주소 ↔ 좌표 변환 |
| `make_map.py` | 검색한 장소를 카카오 지도에 마커로 찍은 `map.html` 만들기 |
| `factcheck.py` | AI가 추천한 장소가 실제로 있는지 카카오로 하나씩 확인 |
| `clean_parking.py` | 전국주차장정보표준데이터 CSV를 판다스로 정리하고 빈 좌표를 카카오로 채우기 |
| `map_app.py` | 장소를 고르면 반경 안의 시설이나 주차장을 지도·숫자·표로 보여 주는 Streamlit 앱 |

실행하려면 `.env.example`을 `.env`로 복사해 카카오 키를 채워야 한다. 주차장 원본 데이터(약 5MB)는 레포에 넣지 않았고, [공공데이터포털](https://www.data.go.kr/)에서 '전국주차장정보표준데이터'를 받아 `data/parking_raw.csv`로 두면 된다.

### 조별 과제: 배리어프리 여행 앱 (중단)

오후 조별 실습에서는 [한국관광공사_무장애 여행 정보](https://www.data.go.kr/data/15101897/openapi.do) API로 배리어프리 여행 앱을 만들려고 했다. 하지만 팀원들의 AI 토큰이 부족해져서 실습을 더 진행하지 못했다.

## AI와 일한 방식

- **AI가 추천한 장소를 그대로 믿지 않았다.** Claude에게 "강남역 혼밥 맛집 10곳"을 물어 받은 답을 [`ai_picks.txt`](kakao-map/data/ai_picks.txt)에 적고, `factcheck.py`로 카카오 검색 결과와 하나씩 대조했다.
- **API 키는 AI에게도 보여 주지 않았다.** `.env`는 내가 직접 만들고, AI는 키가 있는지만 코드로 확인하게 했다.
