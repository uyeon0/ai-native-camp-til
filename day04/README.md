# Day 04 — 스킬 배우기

## 수업

스킬이 무엇인지 배웠다. 스킬은 AI에게 주는 업무 매뉴얼이다. AI는 그럴듯하게 틀리기 때문에, 틀린 곳을 찾아 규칙으로 적어 두면 다음부터 AI가 그 기준대로 일한다. 규칙은 "깔끔하게"처럼 쓰지 않고, 숫자·위치·행동을 넣어 지켰는지 확인할 수 있게 써야 한다.

## 직군별 모임: 스킬 공유

개발 직군끼리 모여서 각자 쓰거나 눈여겨본 스킬을 공유했다.

**개발 방법론·워크플로**
- [superpowers](https://github.com/obra/superpowers): 에이전트용 스킬 묶음이자 개발 방법론
- [spec-kit](https://github.com/github/spec-kit): GitHub이 만든 스펙 주도 개발(SDD) 도구
- [ECC](https://github.com/affaan-m/ECC): 스킬, 메모리, 보안 설정 등을 묶어 에이전트 하네스를 최적화하는 시스템
- [ouroboros](https://github.com/Q00/ouroboros): 인터뷰로 시작해 단계별로 평가하며 스스로 개선하는 에이전트 OS
- [ponytail](https://github.com/dietrichgebert/ponytail): "가장 좋은 코드는 쓰지 않은 코드"라는 관점으로 에이전트가 코드를 덜 쓰게 하는 스킬

**컨텍스트 관리**
- [billion-context](https://github.com/ranxianglei/billion-context): 긴 세션을 위한 컨텍스트 압축 플러그인
- [context-mode](https://github.com/mksglu/context-mode): 도구 출력을 컨텍스트 밖에 두고 검색해서 꺼내 쓰는 플러그인

**분야별 스킬**
- [react-best-practices](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices): Vercel이 만든 React 모범 사례 스킬
- [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): UI/UX 디자인 판단을 돕는 스킬
- [im-not-ai](https://github.com/epoko77-ai/im-not-ai): AI가 쓴 한글을 사람 글처럼 윤문하는 스킬

**참고 채널**
- [Dante Labs 유튜브](https://www.youtube.com/@dante-labs/videos)

## 느낀 점

개발 직군에서는 역시 스펙 주도 개발(SDD)이 대세라는 걸 느꼈다. 날뛰는 AI의 코드 품질을 다스리려고 이렇게 많은 도구가 나와 있다는 점이 흥미로웠다.
