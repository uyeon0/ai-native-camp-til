# D9 프롬프트 정리 노트 (10/26)

## ① 세 가지 유형: 서술형 · 지침형 · 함수형
- 함수형: 틀이 형식을 고정하고, 값이 내용을 바꾼다. 값 하나가 여러 칸에 퍼진다.
- 실습: RPG 캐릭터 카드. {좋아하는 것}을 야구에서 125파운드로 바꿨더니 칭호·스킬·필살기 비유가 전부 바뀌고, 키·스킬 3개·형식은 그대로였다.

## ② 예시 주기: 제로샷 · 원샷 · 퓨샷
- 퓨샷: 예시가 형식을 정한다. 예시에 없는 유형에는 약하므로 예시를 다양하게 넣는다.
- 실습: 제로샷은 형식이 제각각이고 대안·설명이 붙었다. 퓨샷은 `속담 → 이모지` 한 줄 형식을 지켰다.
- 예시에 없는 걸 "하지 말라"는 신호까지는 못 준다. 뜻풀이가 붙어서 나왔다. → ⑤의 제약으로 막는다.
- 이모지 퀴즈는 4/5 정답. "호랑이도 제 말 하면 온다"를 못 맞혔다. "말하면 등장" 같은 구조의 예시가 없었기 때문이다.

## ③ 페르소나: 역할 · 경력 · 분야 · 말투
- 페르소나는 말투·관점을 바꾸고, 정보(단서)는 구체성을 바꾼다. 둘은 따로 작동한다.
- 실습: 푸딩 실종 사건. A(약한 페르소나)와 B(4요소)의 결론은 비슷했다(착각·정리 중 폐기).
- B는 단서별 확인 방법이 구체적이었고, "단정하지 않는다" 제약을 끝까지 지켰다.
- 실무: "시니어처럼 리뷰해 줘"만으로는 말투만 시니어가 된다. 코드·맥락·기준을 같이 줘야 한다.

## ④ 마크다운: 뼈대 5칸 + ''' 자료 상자
- `#역할 #작업 #입력 #제약 #출력` 뼈대에 ''' 자료 상자를 쓰면 자료와 지시가 분리된다. #제약이 지어내기를 막는다.
- 실습: 캠핑 단톡방. 함정 3개(장소 미정, 출발 시간 미정, 유나 음료는 지우가 전한 말)에 모두 걸리지 않았다.

## ⑤ 강도 · 톤 · 숫자
- "짧게" 같은 모호한 말 대신 숫자로 쓴다.
- 실습: 회식 취소 톤 5가지, 라면 격상·축소·숫자 버전. "15자 이내"는 잘 지켰다.
- 긴 숫자 제한(예: 300자)은 범위로 주고 자체 검증을 시킨다("글자 수를 세서 표기해").

## ⑥ 대안 · 이용자 페르소나
- 대안 여러 개 + 역발상 1개를 받아 내가 고른다. 듣는 사람을 정하면 비유가 바뀐다.
- 실습: 역발상 방법이 쓸 만했다. AI는 원래 가장 그럴듯한 답을 내므로, 뒤집으라고 시켜야 확률이 낮은 답이 나온다.
- 한계: "내 상황에 맞는 추천"은 AI가 내 상황을 거의 모르는 상태에서 하는 추측이다. → ⑦ 역질문으로 해결한다.

## ⑦ 레시피 · 역질문 · 인지 검증자
- 역질문: AI가 내 상황을 모르는 문제를 AI가 먼저 묻게 해서 해결한다.

## ⑧ 게임 플레이
- 목적·규칙(턴 수·상태창·승리 조건)·엔딩만 주면 AI가 턴마다 진행한다. 같은 채팅에서 이어서 답한다.
- 실습: 프론트엔드 면접관 롤플레이. 상태창(합격 가능성 55% ▲5, 남은 턴 4/5)이 턴마다 잘 갱신됐다. 1턴 후 중단.
- 내가 계속 입력해야 해서 비용이 크다. 주고받기 자체가 목적일 때(면접 연습, 협상·CS 시뮬레이션)만 쓴다.

## ⑨ 질문 개선
- 보내기 전 체크리스트: 대상 · 범위 · 목적 · 현재 상태 · 잘못된 전제
- 실습: "2026 KBO 우승팀은 누가 될까?" → 짝꿍(Claude Code) 채점 4/10, AI 채점 4/10. 항목별 점수도 같았다.
- 구멍: 목적 0, 현재 상태 0 (10/26은 포스트시즌 중이라는 맥락이 빠짐)
- ★ 질문으로 바꾸니 답이 내가 지정한 틀(선발·불펜·타선·휴식)로 나왔고, 목적(응원팀 정하기)까지 반영됐다.
- 원래 질문은 웹 검색이 현재 상태를 메워 줘서 그럭저럭 괜찮았다. 검색이 없으면 지어낼 위험이 있으니 현재 상태는 직접 넣는다.
- 검증: 같은 사건인데 두 답의 설명이 달랐다(취소 이유가 비 / 태풍). 중요한 사실은 원문을 확인한다.
- ⑨는 ①~⑦을 질문 단계에서 미리 적용하는 도구다.
