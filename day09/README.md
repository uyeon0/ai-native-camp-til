# Day 09 — 프롬프트 기본기

## 수업

오전에는 AI가 엉뚱하게 답할 때 증상에 맞춰 고르는 프롬프트 도구 9가지를 예제로 익혔다. 오후에는 이미지·영상 생성 도구를 다뤘다.

도구마다 실습해 본 결과는 [프롬프트 정리 노트](prompt-notes.md)에 적었다.

| 증상 | 도구 |
|---|---|
| 답이 두루뭉술하다 | ① 세 가지 유형 (서술형·지침형·함수형) |
| 형식이 매번 제각각이다 | ② 예시 주기 (제로샷·원샷·퓨샷) |
| 수준·관점이 안 맞는다 | ③ 페르소나 |
| 요청이 길어지면 놓친다 | ④ 마크다운 뼈대 |
| 중요한 조건을 무시한다 | ⑤ 강도·톤·숫자 |
| 답이 하나뿐이다 | ⑥ 대안·이용자 페르소나 |
| 내가 뭘 빠뜨렸는지 모른다 | ⑦ 레시피·역질문·인지 검증자 |
| 주고받으며 진행해야 한다 | ⑧ 게임 플레이 |
| 내 질문 자체가 애매하다 | ⑨ 질문 개선 |

## 느낀 점

- 페르소나는 말투와 관점을 바꿀 뿐, 답의 구체성은 함께 준 정보가 정한다. "시니어처럼 리뷰해 줘"만으로는 말투만 시니어가 된다.
- AI는 가장 그럴듯한 답을 내기 때문에, 확률이 낮은 답이 필요하면 "뒤집어 봐"처럼 직접 시켜야 한다.
