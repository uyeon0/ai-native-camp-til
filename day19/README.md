# Day 19 — 데이터 정제와 시각화

## 수업

오전에는 타이타닉 데이터로 질문을 먼저 세우고, 결측을 칸마다 다르게 처리한 뒤, 집계와 차트로 답하고 AI가 말한 숫자를 직접 검산했다. 스크립트는 [titanic](titanic/)에 있다.

### 결측은 칸마다 이유를 보고 처리한다

`df.dropna()` 한 줄이면 891행 중 183행만 남는다. Cabin이 77% 비어 있기 때문이다.

| 칸 | 결측 | 왜 비었나 | 처리 |
|---|---|---|---|
| Age | 177 (19.9%) | 3등석에 몰려 있다 | 호칭(Mr · Mrs · Miss · Master)별 중앙값으로 채우고, 비었다는 표시 칸을 남겼다 |
| Cabin | 687 (77.1%) | 1등석 18.5%, 3등석 97.6%가 비었다. 비었다는 사실이 곧 등급 정보다 | "Unknown"으로 채우고 갑판 글자만 `Deck` 칸으로 뺐다 |
| Embarked | 2 (0.2%) | 같은 티켓 · 객실의 일행 한 팀 | 최빈값 S |
| Fare = 0 | 15 | NaN은 아니지만 결측일 수 있다 | 티켓 번호가 회사 직원 · 조선소 쪽 무리로 묶여 있어서, 기록 누락이 아니라 실제로 돈을 안 낸 승객으로 보고 그대로 뒀다 |

### 처리 방법이 답을 바꾼다

나이 결측 177명을 네 가지로 처리해 어린이(0~12세) 생존율을 비교했다.

| 처리 | 어린이 인원 | 어린이 생존율 |
|---|---|---|
| 지우기 | 69명 | 58.0% |
| 전체 중앙값 | 69명 | 58.0% |
| 호칭별 중앙값 | 73명 | 57.5% |
| 0으로 채우기 | 246명 | 37.4% |

0으로 채우면 나이 모르는 177명이 모두 0살 아기가 된다. 대부분 3등석 성인 남자라 어린이 생존율이 크게 떨어진다. 전체 중앙값으로 채우면 177명이 모두 28세 한 칸에 몰린다.

### 차트와 검산

- 생존자 수 막대로 보면 3등석(119명)이 2등석(87명)보다 많이 산 것처럼 보인다. 3등석 승객이 491명으로 훨씬 많았을 뿐이고, 생존율은 24% 대 47%다.
- 차트 제목은 결론 문장으로 쓴다. 예: "등급이 낮을수록 생존율이 떨어졌다 (63% → 47% → 24%)"
- 인원이 10명이 안 되는 칸의 비율은 믿지 않는다. 1명만 바뀌어도 수십 %p가 움직인다.
- C 항구 생존율이 높은 건 C 승객의 절반이 1등석이었기 때문이다. 항구가 생존의 원인은 아니다.
- AI가 말로 한 생존율은 직접 계산한 값과 모두 맞았다. 유명한 데이터라 AI가 기억하고 있었던 것으로, 덜 알려진 데이터라면 그대로 믿으면 안 된다.

## 만든 것

### 다시, 정상

[lions-v9](https://github.com/uyeon0/lions-v9) ([배포](https://lions-v9.streamlit.app)): 오후에는 조별 과제 대신 혼자 작업했다. 삼성 라이온즈가 암흑기(2016~2023)를 지나 2026년 한국시리즈에서 다시 우승하기까지를 KBO 정규시즌 기록으로 보여 주는 Streamlit 페이지다. 이야기를 9이닝으로 나눈 스크롤 메인 페이지와 분석 페이지 4개로 이뤄져 있다.

오전에 배운 순서를 그대로 썼다.

- **숨은 결측**: `ERA`에 `-` 49개, `WPCT`에 `-` 2,091개가 NaN으로 잡히지 않고 들어 있었다.
- **비교 기준 맞추기**: 시즌마다 경기 수(80~144경기)와 타고투저 정도가 달라서, 합계 대신 리그 평균 대비 지표(R+, ERA+)로 비교했다.
- **검산**: 선수 기록을 합쳐 만든 팀 기록을 2021년까지의 공식 팀 기록과 비교했다. 팀 경기 수 구하는 방식을 바꾸자 공식 기록과 맞는 팀 × 시즌이 322개 중 18개에서 304개로 늘었다.
- **데이터에 없는 것**: 한국시리즈 결과와 2021년 순위 정정은 정규시즌 데이터에 없어서 기사에서 모으고 출처를 남겼다.
