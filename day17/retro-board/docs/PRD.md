# PRD — 수업 회고 모음판

> 버전 v1 · 2026-11-05 · Streamlit 앱 · 로컬 전용

## 한 줄 소개
수업이 끝날 때 배운 것·막힌 것·물어볼 것을 적으면, 날짜별 md 파일로 내 폴더에 쌓아 주는 개인용 앱

## 누구의 어떤 문제인가
- **주인공**: 캠프를 듣는 나 한 명. 다른 사용자는 없다.
- **문제**: 매일 배우는 게 많은데 따로 적어 두지 않으면 며칠 뒤에 기억이 안 난다. 회고 파일을 직접 만들면 날짜와 형식이 매번 달라져서 나중에 모아 보기 어렵다.
- **언제 여나**: 오전·오후 실습이 끝날 때, 또는 하루를 마칠 때 1~2번 연다.

## 범위
- 내 컴퓨터에서 `streamlit run app.py`로만 띄운다. 배포하지 않는다.
- 앱은 회고를 **쓰고 읽기만** 한다. 고치거나 지우고 싶으면 md 파일을 직접 연다.
- 로그인, 검색, 태그, 통계, "N일차" 표시는 v1에 넣지 않는다.
- 입력 길이는 제한하지 않는다.

## 데이터
- 저장 폴더: 기본은 `retros/`. 환경변수 `RETRO_DIR`이 있으면 그 폴더를 쓴다. (예: Obsidian 폴더, 시험용 `tests/tmp/`)
  - 상대 경로는 `app.py`가 있는 폴더 기준으로 본다. 실행 위치와 상관없다. `~`는 홈 폴더로 펼친다.
  - 폴더가 없으면 첫 저장 때 만든다.
  - `retros/`는 `.gitignore`에 넣는다. 개인 회고는 레포에 올리지 않는다.
- 파일: 하루에 하나, 이름은 `YYYY-MM-DD.md` (예: `2026-11-05.md`)
- 파일 모양 (블록 2개가 쌓인 경우):

  ```markdown
  # 2026-11-05

  ## 14:30
  - 배운 것: 서브에이전트에 역할을 나눠 주면 리뷰가 덜 뭉개진다
  - 막힌 것: Streamlit에서 저장 후 입력칸 비우기
    session_state를 언제 지워야 하는지 모르겠다
  - 물어볼 것: session_state 초기화 타이밍

  ## 18:10
  - 배운 것: PRD 빈틈은 리뷰어 에이전트로 먼저 거른다
  ```

  - 제목 `# 날짜`는 그날 파일을 처음 만들 때 한 번만 쓴다.
  - 빈 줄 규칙: 제목 뒤 빈 줄 1개, 블록과 블록 사이 빈 줄 1개, 파일 끝은 줄바꿈 1개(`\n`)로 끝난다.
  - 저장할 때마다 파일 끝에 `## HH:MM` 블록을 하나 붙인다. 이미 있는 내용은 건드리지 않는다.
  - 내용이 다르면 같은 분에 두 번 저장해도 블록을 그대로 하나 더 붙인다. (`## 14:30`이 두 개 생길 수 있다)
  - 직전 블록과 세 칸 내용이 모두 같으면 붙이지 않는다. 버튼을 연달아 눌러도 한 번만 저장된다.
  - 비워 둔 칸은 그 줄을 쓰지 않는다.
  - 한 칸에 여러 줄을 쓰면 둘째 줄부터 앞에 공백 2칸을 붙여 같은 항목 아래에 둔다.
    - 칸 안의 빈 줄(공백뿐인 줄 포함)은 지운다.
    - 각 줄 끝 공백은 지운다.
    - `#`, `-` 같은 md 문법으로 시작하는 줄도 이스케이프하지 않고 그대로 둔다. (들여쓰기 2칸 때문에 제목으로 읽히지 않는다)
- 날짜와 시각은 내 컴퓨터 시간 기준이다.
  - 파일 날짜는 **쓰기 화면에 보이는 날짜**다. 23:59에 화면을 열어 두고 00:01에 저장해도 화면에 보이던 전날 파일에 들어간다. 블록 시각은 저장을 누른 순간의 시각이다.

## 기능 (출시 순서)

### F1 회고 쓰기
화면: 탭 `✏️ 쓰기`. 맨 위에 오늘 날짜, 아래에 `배운 것` · `막힌 것` · `물어볼 것` 입력칸 3개와 `저장하기` 버튼.

다 됐다 기준:
- [x] 오늘 파일이 없을 때 저장하면 `retros/2026-11-05.md`가 생기고, 위 파일 모양대로 `# 2026-11-05` 제목과 `## 시각` 블록이 들어간다.
- [x] 오늘 파일이 이미 있을 때 저장하면 기존 내용은 한 글자도 바뀌지 않고, 빈 줄 1개 뒤에 `## 시각` 블록이 하나 더 붙는다.
- [x] 세 칸 중 하나만 채워도 저장되고, 채운 항목 줄만 파일에 들어간다.
- [x] 세 칸이 모두 비어 있거나 공백뿐이면 "한 칸 이상 적어 주세요"가 뜨고 파일은 바뀌지 않는다.
- [x] 칸 앞뒤 공백은 지우고 저장한다.
- [x] 한 칸에 두 줄을 쓰면 둘째 줄이 공백 2칸으로 들여쓰여 저장된다. 칸 안의 빈 줄은 저장되지 않는다.
- [x] 저장에 성공하면 세 칸이 비워지고 "저장했어요: retros/2026-11-05.md (오늘 2번째)"처럼 저장 폴더 이름/파일 이름과 오늘 몇 번째 회고인지 보인다.
  - 경로는 저장 폴더의 마지막 이름 + 파일 이름으로 보여 준다. (`RETRO_DIR=~/notes/camp`이면 `camp/2026-11-05.md`)
  - N은 그 파일에서 정확히 `## HH:MM` 모양(`^## \d{2}:\d{2}$`)인 줄의 개수다. md를 직접 고쳐서 숫자가 어긋나는 건 허용한다.
- [x] 저장에 실패하면(폴더 권한 없음, `RETRO_DIR`이 파일이거나 만들 수 없는 경로 등) "저장하지 못했어요: (이유)"가 뜨고 입력칸 내용은 그대로 남는다.
- [ ] `저장하기`를 누르면 저장이 끝날 때까지 버튼이 잠긴다(`disabled`). 성공·실패와 상관없이 끝나면 다시 풀린다.
- [x] `저장하기`를 빠르게 두 번 누르면 블록은 하나만 붙는다.
- [x] 직전 블록과 세 칸 내용이 같으면 파일은 바뀌지 않고 "방금 저장한 내용과 같아요. 새 내용을 적어 주세요"가 뜬다.
- [x] `RETRO_DIR`을 지정하면 그 폴더에 저장되고 `retros/`는 바뀌지 않는다.

### F2 날짜별 모아보기
화면: 탭 `📚 모아보기`. 왼쪽에 날짜 목록(최신순 라디오 버튼, 개수 제한 없이 스크롤), 오른쪽에 고른 날의 내용.

다 됐다 기준:
- [ ] 저장 폴더의 `YYYY-MM-DD.md` 파일이 최신 날짜부터 목록에 나온다.
- [ ] 처음 열면 가장 최근 날짜가 골라져 있다.
- [ ] 날짜를 고르면 그 파일 내용이 md 서식(제목, 목록)으로 보인다.
- [ ] 이름이 `YYYY-MM-DD.md` 모양이 아닌 파일(예: `memo.md`, `.DS_Store`)은 목록에 나오지 않는다.
- [ ] 모양은 맞지만 실제 날짜가 아닌 파일(예: `2026-13-45.md`)도 목록에 나오지 않는다.
- [ ] 고른 파일을 읽지 못하면(UTF-8이 아님, 깨짐 등) "이 파일을 열 수 없어요"가 보이고 목록은 그대로 남는다.
- [ ] 파일이 하나도 없거나 저장 폴더가 없으면 "아직 남긴 회고가 없어요"가 보인다.
- [ ] F1에서 저장한 뒤 모아보기 탭을 열면 방금 쓴 내용이 보인다.

## 시험 방법
- md 문자열 만들기(블록 만들기, 여러 줄 들여쓰기, 빈 칸·빈 줄 빼기)는 파일을 모르는 순수 함수로 두고 단위 테스트한다.
- 파일 읽기·쓰기는 `storage.py`에서만 하고, 시험할 때는 `RETRO_DIR`을 임시 폴더로 지정한다. 진짜 `retros/`는 시험 중에 바뀌지 않는다.
- 시각은 함수 인자로 받아서, 시험에서 날짜·시각을 고정할 수 있게 한다.
